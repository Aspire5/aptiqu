# Approved application fonts

Outfit headings and Plus Jakarta Sans reading text are bundled at weights 400,
500, 600, 700 and 800. These are byte-for-byte copies of the verified static
Google Fonts files used in the visual fixtures. Sources, SHA-256 values and
lengths are recorded in SOURCES.json; each family has its OFL license.

The asset directories preserve the filenames expected by google_fonts 8.1.0.
main disables runtime font fetching, so appearance does not depend on a first-run
font download. Google Sans remains the separately bundled provider-button font.
No family, weight, size or palette is replaced by this provisioning change.
